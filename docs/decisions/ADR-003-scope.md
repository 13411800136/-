# ADR-003：M 范围取舍与 F 不做清单

- 日期：2026-11-03
- 状态：已接受
- 关联：R01-R27；A01-A35

## 背景

任务包允许在 M 中只做单产品、单采购、单生产任务、无电镀、一次全合格质检，但要求真实认证、服务端权限、数据库、事务、幂等、库存并发、导出、附件、通知、看板、异常、审计与交付文档。三至四周内必须优先保证这些质量底线，而不是堆 F 页面。

## 决定

### 做（M）

- 单产品订单；一单一采购单、单配件；一次到货（可累计多次，但演示一次到齐）。
- 单生产部门/单任务；一次反馈或累计反馈，数量受限；单价开关。
- 一次全检全合格；管理员 PASS 放行；包装/发货数量闸门；足量完成。
- 手工库存、并发保护、幂等、利润、时间线、PDF 附件、订单 xlsx、通知、看板、异常、审计、迁移、种子、备份恢复、测试与文档。

### 不做（F 或范围外）

| 能力 | 决定 | 原因/边界 |
| --- | --- | --- |
| 多产品/多明细 | 不做 | 会扩散到逐产品包装/发货、汇总与看板；M 允许单产品 |
| 多采购单/多配件/供应商报价 | 不做 | 需要分单/换算/对账；不自动分单 |
| 电镀 | 不做 | R06 M 明确不启用；页面 N/A，不伪造 |
| 部分到货投产/超量确认 | 不做 | 需要材料确认、原因、上限策略；M 要求到齐 |
| 多生产任务/部门回流/工艺记录 | 不做 | 需要轮次与可流转量模型；M 单任务 |
| 返工/报废/阈值/再检 | 不做 | 数量守恒与补生产复杂；M 全合格 |
| 10 分钟撤销/超时修正 | 不做 | 下游依赖与时钟/逆序；M 明确拒绝 |
| Excel 导入 | 不做 | M 允许不提供；受控页面维护 |
| 多格式报表/导出历史 | 不做 | M 只需订单 xlsx；审计中有导出记录，不作为 F 验收 |
| 定时交期提醒 | 不做 | 需要调度、业务日、去重、补执行 |
| 多产品看板/成本指标 | 不做 | 只做 M 真实汇总 |
| 移动 App/支付/税务/快递 | 不做 | 范围外 |

## 后果

- 系统能完整演示一条真实业务链，但不应被宣称为“完整工厂 ERP”。
- 未选 F 不提供可用入口；撤销/返工/导入等请求明确 409/404，避免“接受但不处理”。
- 若后续加 F，先更新范围矩阵、PRD、接口/数据/权限/状态合同与测试，再实现；不把 F 计入 M 完成度。

## 验证

功能状态表逐项标注 M/F；门禁测试覆盖单产品/单任务/全合格边界；README 与答辩明确“M 已验收、F 仅切片/未选做”。
