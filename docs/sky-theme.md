# 蓝天白墙主题（v1.8.0）

- 背景插画：用户为本项目提供的《墙头猫咪》，文件 `frontend/src/assets/sky-cat.jpg`
- 实现文件：`frontend/src/styles/sky-theme.css`、`frontend/src/app/AppBackground.tsx`
- 覆盖层：`rhine-glass.css` 仍保留结构与玻璃基础，`sky-theme.css` 在其后加载，负责蓝色调、背景插画与组件配色
- 原则：只改视觉，不改 DOM 结构、交互流程、接口与数据

## 视觉基调

| 元素 | 取值 |
| --- | --- |
| 天空蓝纸面 | `#e9f4fb` → `#dcecf7` |
| 主文字 | 深海军蓝 `#102a3c` |
| 次文字 | 蓝灰 `#4a6577` / `#7893a6` |
| 强调色 | 珊瑚橙 `#ff8a5b`（对应飞机与猫耳，用于编号、提醒、关键按钮） |
| 主按钮 | 深蓝渐变 `#1f5478 → #123a54` |
| 利润面板 | 深海军蓝渐变，珊瑚色高光 |
| 玻璃 | `backdrop-filter: blur(22px) saturate(1.12)`，白蓝半透明底，1px 白边 |

## 背景处理

- 图片以 `cover` 铺满，指针移动时产生约 10px 的反向视差，`prefers-reduced-motion` 下关闭。
- 顶部 0–32% 叠一层更实的白蓝渐变，保证页标题与说明文字在天空/飞机上仍可读。
- 下半部保留白墙与猫的细节；卡片为半透明玻璃，猫会从卡片后透出来，形成层次。
- 颗粒与暗角保留，暗角改为冷蓝色调。

## 布局与组件

- 悬浮玻璃侧栏、悬浮顶栏、大圆角卡片延续 v1.7 的非常规布局。
- 侧栏选中项改为深蓝胶囊，编号与提醒用珊瑚橙。
- 表格、筛选条、弹窗、输入框统一为白蓝玻璃；表头浅蓝、行悬停浅蓝。
- 登录页：插画铺满，左侧标题区加白蓝渐层，右侧玻璃登录卡。

## 可读性

- 正文与背景对比度保持在 4.5:1 以上；图片只作为背景，不参与文字承载。
- 玻璃层透明度 0.5–0.78；通知列表、审计表格等长文本区域透明度更高。
- 窄屏（≤920px）背景改为偏右构图，避免猫脸被侧栏遮挡。

## 回退方式

1. 从 `frontend/src/main.tsx` 移除 `import './styles/sky-theme.css';`
2. 将 `AppBackground.tsx` 还原为上一版方块背景（见 git 历史 `v1.7.0`）
3. 删除 `frontend/src/assets/sky-cat.jpg`

回退后回到 v1.7.0 的奶油玻璃主题；业务代码与数据不受影响。
