# 设计方向：工位轨道（Station Rail）

- 日期：2026-11-14
- 适用版本：v1.3.1 视觉层（`frontend/src/styles/line-theme.css`）
- 方法来源：`houxin0010/distinctive-ai-design` 的「探索 → 定义 → 交付」流程

## 三个候选方向

| 方向 | 构图 | 隐喻 | 判断 |
| --- | --- | --- | --- |
| A 车间调度台 | 深色仪表盘、密集信号灯 | SCADA 控制室 | 有辨识度，但深色大面积会牺牲长时间阅读与打印/截图可读性 |
| B 工单纸本 | 纸质工单、印章、骑缝线 | 车间纸卡 | 触感强，但管理员表格与筛选会被“纸感”拖慢 |
| C 工位轨道 | 左侧工位轨道 + 顶部工序轨 | 流水线与工位牌 | **采用**：主任务就是“一批货沿工位推进”，隐喻直接服务导航与状态判断 |

## 采用方向的 brief

- **用户与主任务**：管理员在桌面推进 9 个阶段、看全局；物流/生产/品控/包装在平板上只看本工位待办。
- **目标感受**：像站在车间看板前——克制、可核对、有工序感，而不是通用 SaaS 后台。
- **核心隐喻**：订单是一张沿轨道移动的工单，页面是工位的操作面。
- **构图与层级**：左侧窄轨道（带刻度与工位编号）→ 顶部工序轨 → 工单纸面（数据）→ 右下操作区。
- **色彩与字体**：墨黑、纸白、信号琥珀；标签用小号大写等宽字，数字一律等宽对齐。
- **关键交互**：工位/阶段用方形标记与连接轨表达“已过、当前、未到”；当前工位用琥珀信号，不用发光。
- **避免**：大面积渐变、圆角胶囊堆叠、每个卡片都相同的阴影、装饰性图标墙。
- **第一版范围**：登录、管理端外壳与看板、订单列表/详情工序轨、表格与状态、现场工作台、弹窗与提示。

## 实现边界

- 只改视觉层：新增 `line-theme.css` 在 `global.css` 之后加载；不改路由、接口、状态与业务逻辑。
- 保留原有类名与 DOM 结构，便于回滚：删除该文件与 `main.tsx` 中的 import 即恢复原视觉。
- 保留 `prefers-reduced-motion` 与窄屏断点行为。

## 独立评审结论（2026-11-14，基于真实截图）

- 整体完成度：**6.5 / 10**。方向立住，纸面质感与数字排版接近专业；轨道尚未成为骨架，首屏与主操作未收束。
- 已在本轮修复：状态/暗面板对比度、看板两处墨面并存、空状态重复主按钮、工序轨可读性与吸顶、登录页工位数不一致。
- **仍然存在（未在本轮解决）**：
  1. 看板首屏仍以问候语与 KPI 为主，待办与临期在第二屏；需要重新排布而非压缩间距。
  2. 订单列表行内没有迷你工序轨，跨页“轨道”隐喻尚未贯通。
  3. 详情页同一动作仍有四个入口（页头、采购卡、空状态、右栏“下一步”），本轮只做了视觉降级。
  4. 日期与页脚存在多种写法，尚未统一。
- 评分只用于观察改进，不作为功能验收证据。
