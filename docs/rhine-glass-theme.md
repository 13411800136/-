# 奶油玻璃主题（v1.7.0）

- 参考对象：Wallpaper Engine 工坊项目 `3799142774`（RHINE LAB「Synthesize Information Analysis OS」）的视觉语言
- 实现文件：`frontend/src/styles/rhine-glass.css`、`frontend/src/app/AppBackground.tsx`
- 原则：只改视觉，不改 DOM 结构、交互流程、接口与数据

## 从参考里取了什么

| 参考特征 | 本项目落地 |
| --- | --- |
| 奶油/象牙色纸面、低饱和暖色 | 全站底色改为 `#f7f2e6 → #e9dfcc` 渐变，文字为暖黑 `#17150f` |
| 成排的立体档案方块 | `AppBackground` 用三层行内方块模拟档案柜，带高光顶部、柔和投影与轻微旋转；指针移动产生 10px 级视差 |
| 大面积留白与单一强调色 | 强调色统一为琥珀 `#d59b32`，只用于编号、状态与关键按钮 |
| 极简无衬线排版 | 保留原有字体栈，仅调整字重、字距与层级 |
| 柔和阴影与浮起感 | 卡片用三层阴影：大范围柔和投影 + 近距接触阴影 + 顶部内高光 |
| 玻璃质感 | `backdrop-filter: blur(22px) saturate(1.1)`，半透明白色渐变底，白色 1px 边 |

## 非常规布局

- 侧栏不再通栏贴边，而是**悬浮圆角面板**（`inset: 18px auto 18px 18px`，圆角 26px）；
- 顶栏改为主内容区内的**悬浮玻璃条**（sticky，上距 16px，圆角 18px）；
- 主内容左移 280px 让出浮动侧栏；页脚 `margin-top: auto` 固定在视口底部；
- 登录页左侧改为透明底 + 深色大字，右侧玻璃卡浮在档案方块背景上。

## 交互与可读性

- 玻璃层透明度控制在 0.46–0.8，正文对比度保持 4.5:1 以上；表格行仍为实色文字。
- 背景方块只出现在页面下半部与内容间隙，避免干扰表格阅读。
- `prefers-reduced-motion` 下关闭背景视差与所有按钮动效。
- 窄屏（≤920px）侧栏恢复抽屉形态，背景方块降低到 70% 高度。

新增 `.btn-white` 白色按钮变体，用于看板「查看订单流水」入口：白底、墨字、柔和投影，悬停时琥珀描边并上浮 1px。

## 回退方式

删除 `frontend/src/main.tsx` 中 `rhine-glass.css` 的引入，并移除 `App.tsx` 中的 `<AppBackground />`，即回到 v1.6.0 的工位轨道视觉；业务代码无需改动。
