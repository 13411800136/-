## 2. 架构决定

| 决定 | 备选 | 选择理由 | 对实现/测试/交付的影响 |
| --- | --- | --- | --- |
| Node 24 + Fastify 5 + `node:sqlite` | PostgreSQL/Prisma | 零外部服务、Windows 可复现、事务/约束真实 | 单写者；并发测试为两连接正确性，不宣称吞吐 |
| 单进程同时服务 API 与静态前端 | 前后端分离 + Nginx | 同源、无 CORS、启动步骤少 | 前端需先 build；开发用 Vite 代理 |
| React 19 + Vite + 手写 CSS | UI 组件库 | 控制视觉与响应式，不引入额外运行时 | 组件/页面需自己维护；构建约 389 KB JS |
| Opaque session + scrypt | JWT + bcrypt | 可撤销、零原生依赖、停用即时失效 | 每请求查会话；进程内限流 |
| 整数分 + 手写业务守卫 | 浮点/通用状态机 | 金额精确、规则显式可测 | 规则集中在 service，需完整测试 |
| 手写 SQL 迁移 + checksum | ORM 迁移 | 透明、无生成器依赖 | 需自己写 SQL 与迁移评审 |

请求路径与模块边界见 [architecture.md](../docs/architecture.md)；接口见 [api-contract.md](../docs/api-contract.md)。

## 3. 依赖与纵向拆解

```text
T01 环境/迁移/种子
  └─ T02 认证/会话/角色
       ├─ T03 基础数据/员工
       └─ T04 订单/采购/到货
            ├─ T05 生产/单价开关
            │    └─ T06 质检/放行
            │         └─ T07 包装/发货/完成
            ├─ T08 库存并发/幂等
            ├─ T09 利润/时间线/看板
            ├─ T10 附件/导出/通知/异常/审计
            └─ T11 前端管理员/现场
                 └─ T12 测试/恢复/文档/答辩
```

纵向任务定义：能从页面/API 走到真实数据库并被验证的小闭环。认证、并发、幂等、迁移风险前置；不先把所有页面画完再接后端。

## 6. 风险、环境与安全

| 风险/未知 | 影响 | 提前验证 | 缓解/回退 |
| --- | --- | --- | --- |
| SQLite 单写者 | 并发/多实例限制 | 两连接并发测试 | 文档声明；未来迁 PostgreSQL |
| 状态/数量规则漏守卫 | 超量/死路/数据不一致 | A07/A10/A12/A14/A15 逐项拒绝测试 | 守卫集中在 service，补测试 |
| 幂等重试被状态误拒 | 响应丢失后重复/失败 | 同键重放 E2E + 集成 | 守卫移入事务；保留 409 语义 |
| 错误处理器封装 | 前端读不到错误码 | 集成测试断言统一格式 | 注册顺序前移 |
| 时间/时区错位 | 交期/看板差一天 | 日期单测 + 北京时间格式 | 日期字符串不转 UTC；Intl 固定时区 |
| 文档与实现漂移 | 答辩无法追溯 | 追溯表/状态表逐项核对 | 改代码同步文档；未实现如实标注 |
| 测试库指向真实库 | 数据损坏 | 临时目录 + 路径检查 | 不使用真实库；恢复只写新目录 |
| 交付包混入运行数据 | 隐私/体积 | `.gitignore` + 打包前清单 | 只提交源码/文档/证据；数据/备份排除 |

测试库隔离：集成测试每个环境使用系统临时目录；E2E 使用本机演示库且只创建合成订单；恢复目标必须为空目录。
